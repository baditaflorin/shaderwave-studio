# 0043 - Domain Vocabulary And UI Language

## Status

Accepted

## Context

Browser errors such as `Unable to decode audio data` are technically true but not useful for the intended music-video workflow.

## Decision

Use audio-production terms: audio health, silent track, clipped peaks, partial stream, container, render range, confidence, and provenance.

## Consequences

Every warning and error needs what, why, and next-step text.

## Alternatives Considered

Generic developer terms were rejected because they make failures feel arbitrary.
