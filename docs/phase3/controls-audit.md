# Phase 3 Controls Audit

Date: 2026-05-10

## Green

- `Choose`
- `Demo`
- `Cancel analysis`
- `Play/Pause`
- Timeline scrubber
- Shader preset selector
- Intensity, color shift, bloom, smoothing sliders
- Export duration, FPS, width, height fields
- `Export MP4`
- `Cancel export`
- `Download last export`
- `Download provenance`
- `Apply` suggested export
- `Star`
- `Support`

## Yellow

- Runtime capability badges
  They reflect capability presence, but do not link to next-step guidance.
- Debug overlay via `?debug=1`
  Useful, but undiscoverable and not documented in README.

## Red

- No import-state control
- No save-project control
- No copy-to-clipboard output control
- No reset / clear-state control

## Phase 3 Goal

Add explicit session controls so every realistic end-to-end user action has a visible control, not just an implementation path.
